# sd1004-estructuras

Hice un diagrama sencillo con tres estructuras de datos: 

Arreglo: cinco casillas con los números 12, 7, 25, 8, 4. Cada elemento tiene una posición o índice. 

Lista enlazada: cuatro nodos (10 → 22 → 5 → 31) donde cada nodo apunta al siguiente y el último termina en NULL. 

Pila: una torre de platos. El plato que se pone de último es el primero que se puede sacar, siguiendo la regla LIFO. 

Me costó más la lista enlazada, fue la que más me costó dibujar. Al principio pensaba que era solamente poner los números uno al lado del otro, pero después entendí que cada nodo tiene que apuntar al siguiente. Eso fue lo que más trabajo me dio representar. Reto mental 

1. WhatsApp
 Estructura que creo que usa: arreglo.
 Creo que puede usar arreglos para guardar y organizar los mensajes de una conversación, porque los mensajes aparecen en un orden y se pueden recorrer uno por uno.

2. Spotify
Estructura que creo que usa: lista enlazada.
Una lista de reproducción tiene canciones que van una después de otra. Me parece que una lista enlazada representa bien esa idea porque cada canción puede estar relacionada con la siguiente.
 
3. Instagram
Estructura que creo que usa: pila. 
Creo que una pila puede servir para algunas acciones que realizo dentro de la aplicación, como cuando entra a una pantalla y después regresa a la anterior. La última pantalla a la que entre será la primera que se quita al regresar, parecida a una pila de platos.
